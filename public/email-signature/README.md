# Mooncrab Siargao email signature

The recommended signature uses the full Mooncrab logo, verified contact details, and two useful QR codes: booking and WhatsApp. The expanded version adds Instagram and Google Maps QR codes. All text links remain clickable, so recipients can use them on the same device.

The cocoa **Chat on WhatsApp** button is the primary contact. The outlined Facebook, Instagram, and website buttons remain readable when remote images are blocked. The Facebook button opens Messenger for Moon Crab IAO. Button icons are from Bootstrap Icons under the included MIT license.

## Install the recommended signature

1. Open https://mooncrabsiargao.com/email-signature/ after the update is live.
2. Click **Copy signature**. If your browser does not support that button, open the standalone signature, select the rendered signature, and copy it. Copy the visible design, not its HTML source.
3. Paste into your email app’s signature editor. Keep the original formatting.
4. Send yourself a test email. Check the logo, links and QR codes in the received message. Some recipients may need to allow remote images.

### Spacemail — greetings@mooncrabsiargao.com

Sign in to Spacemail Webmail for greetings@mooncrabsiargao.com. Open **Settings → Signature → Manage signatures → + New signature**. Name it Mooncrab, paste the rendered signature with its formatting, then select the tick to make it the default. Check the saved notification and send yourself a test. The connected Spacemail tools cannot edit mailbox signatures; this package does not claim that your mailbox settings have changed.

Official guide: https://www.spaceship.com/en-GB/knowledgebase/create-email-signature-spacemail/

### Gmail

Settings → See all settings → General → Signature → Create new. Paste the signature, choose it under Signature defaults, then Save Changes at the bottom of the page.

### Apple Mail

Mail → Settings → Signatures. Select your account and add a signature, turn off **Always match my default message font**, then paste the rendered signature. Choose it for the account.

### Outlook

Open Settings and search for **Signatures** (or **Mail → Compose and reply** in Outlook on the web). Create a signature, paste the rendered design, select when it should be added, and save. Classic Outlook uses **File → Options → Mail → Signatures**. Menu labels vary by version.
